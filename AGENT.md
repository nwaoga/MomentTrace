# MomentTrace Agent Handoff

This repository follows the same repo-local AI continuity structure as `NthTerm`.

Start here:

1. `ai/project-plan.md` - current priority, active roadmap, Azure DevOps mapping, and handoff checklist.
2. `ai/architecture.md` - project structure, responsibilities, and coding constraints.
3. `ai/stories.md` - backlog, completed work, and QA notes.
4. `ai/decisions.md` - recent decisions and known open questions.
5. `ai/prompts.md` - guardrails and reusable handoff prompts.
6. `README.md` - stable product, build, run, architecture, and release documentation.

Keep `README.md` stable and user/developer-facing. Keep active plans, agent continuity, current priorities, and working notes under `ai/`.

Do not commit local secrets. `ai/local-secrets.ps1` is ignored by Git.
